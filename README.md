# Matthew Liu — Personal Universe

A one-page portfolio where each project is a constellation. The interface keeps a calm central introduction, places projects around it in chronological order, and opens each project as an inspectable lens.

## Run locally

```bash
bun install
bun run dev
```

## Verify

```bash
bun test
bun run test:e2e
bun run build
```

## Artifact policy

Project previews are labeled specimens based on real project concepts or repository material. They are not presented as screenshots of interfaces that do not exist.

## Stack

React, TypeScript, Vite, Vitest, Playwright, and custom CSS. The production site is deployed on Vercel.
