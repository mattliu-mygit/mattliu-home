# Matthew Liu — Personal Universe

A one-page portfolio organized as a quiet, interactive universe. Projects and
quotes are separate constellations: each star selects an item, project stars
open an inspectable lens, and scrolling introduces a restrained sense of orbit.

## Run locally

```bash
bun install
bun run dev
```

## Verify

```bash
bun run test
bun run test:e2e
bun run build
```

## Artifact policy

Project previews are labeled specimens based on real project concepts or repository material. They are not presented as screenshots of interfaces that do not exist.

## Stack

React, TypeScript, Vite, Vitest, Playwright, and custom CSS. The production site is deployed on Vercel.
